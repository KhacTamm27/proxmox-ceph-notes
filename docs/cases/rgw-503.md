# RGW/S3 trả 503 hoặc timeout, upload lỗi

[← Mục lục](../../README.md)

**Triệu chứng:** Client S3 nhận 503/timeout, upload thất bại, RGW phản hồi chậm.

**Nguyên nhân hay gặp:** Daemon RGW treo hoặc crash, pool RGW đầy hoặc có slow ops, PG inactive trên pool index/data.

## Các bước xử lý

1. Cluster Ceph phía sau có ổn không

```bash
ceph -s
ceph health detail
ceph df
```

2. Trạng thái và log daemon RGW

```bash
systemctl status ceph-radosgw@rgw.<n>
journalctl -u ceph-radosgw@rgw.<n> --since "30 min ago"
```

3. Nếu lỗi theo một user hoặc bucket: xem quota và trạng thái

```bash
radosgw-admin user info --uid=<uid>
radosgw-admin bucket stats --bucket=<bucket>
```

4. Nếu chỉ RGW treo mà cluster ổn thì restart daemon

```bash
systemctl restart ceph-radosgw@rgw.<n>
```

## Lưu ý

Hết quota thường trả 403 QuotaExceeded chứ không phải 503. Nếu có nhiều RGW sau load balancer, restart lần lượt từng cái để không mất dịch vụ.
