# RGW/S3 trả 403 (AccessDenied, SignatureDoesNotMatch, QuotaExceeded)

[← Mục lục](../../../README.md) · Case study Ceph

**Triệu chứng:** Client S3 nhận 403 dù cluster khỏe: AccessDenied, SignatureDoesNotMatch hoặc QuotaExceeded.

**Nguyên nhân hay gặp:** Sai access/secret key, user bị suspend, vượt quota, bucket policy hoặc ACL chặn, giờ client lệch quá nhiều so với server.

## Các bước xử lý

1. Xem key, trạng thái suspended và quota của user

```bash
radosgw-admin user info --uid=<uid>
```

2. So dung lượng và số object của bucket với quota

```bash
radosgw-admin bucket stats --bucket=<bucket>
```

3. Nếu vượt quota thì nâng hạn mức

```bash
radosgw-admin quota set --quota-scope=user --uid=<uid> --max-size=<bytes> --max-objects=<n>
```

4. Kiểm tra giờ trên máy client và trên RGW (SignatureDoesNotMatch hay do lệch giờ)

```bash
timedatectl
```

## Lưu ý

Sau khi đổi quota có thể cần radosgw-admin quota enable. Lỗi chỉ xảy ra với một bucket thì kiểm tra bucket policy và ACL.
